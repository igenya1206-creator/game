# COSTUME SELECT — 画像レイヤー版

CSS図形だったキャラクター表示を、画像を重ねるレイヤー方式に作り替えたものです。

## 構成
- `index.html` / `styles.css` / `app.js` — アプリ本体
- `assets/base/underwear.png` — ベースの体（下着姿・全身・正面向き）
- `assets/hair/default.png`, `assets/hair/twin.png` — 髪型2種
- `assets/costume/school.png`, `nurse.png`, `maid.png` — 衣装3種（スカート丈込みで固定）

今入っている画像はすべて仮のプレースホルダーです（色分けした図形にラベルが入っているだけ）。
レイヤーが正しく重なって表示されることの確認用です。

## 本番の絵を用意する時の条件
- 透過PNG
- 全パーツ共通のキャンバスサイズ（プレースホルダーは800×1600pxで作成）
- 正面向き・直立ポーズで統一、体の比率・位置を全パーツで揃える

## 差し替え方
同じファイル名で `assets/` 以下の該当ファイルを上書きするだけで反映されます。
`app.js` や `styles.css` 側の修正は不要です（重なる順序は base → costume → hair の固定）。

## 変更点まとめ（旧バージョンから）
- 体型スライダー（バスト/ウエスト/ヒップ）を削除
- スカート丈スライダーを削除（衣装ごとに固定丈）
- 登場シーン（cinematic演出）を削除
- 衣装を7種→3種（スクール／ナース／メイド）に絞り込み
- 髪型を4種→2種（デフォルト／ツイン）に絞り込み
- キャラクター表示をCSS図形からPNGレイヤー方式に変更
